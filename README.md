# ASR Trading — Site 01 of 10

This repository contains the immersive agricultural-trading concept site. GitHub Actions builds it and publishes the static site on GitHub Pages.

The source package is temporarily split into text segments in `source-package/` so the Pages workflow can reconstruct it on the first build. The first successful run automatically expands the source files into their normal project folders and removes those transport segments.

## Site safeguards

- The 3D shipping routes are illustrative, not live logistics data.
- The site does not claim certifications, clients, volumes, inventory, or completed trades.
- The enquiry form opens a local email draft; no submissions are stored.
- Confirm the registered business name, contact address, products, destination coverage, and service scope before using the site for buyer verification.
