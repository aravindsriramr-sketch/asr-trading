# ASR Trading — Site 01 of 10

An independently addressed agricultural-trading concept site built with Vite and Three.js. The hero globe is real-time 3D, interactive by mouse/touch, and intentionally labeled as an illustrative route study rather than live shipping data.

## Local setup

Requires Node.js 20.19+ or 22.12+ (Vite 7 requirement).

```sh
npm ci
npm run dev
npm run build
npm run preview
```

## Deploy

The repository includes a GitHub Pages workflow at `.github/workflows/deploy.yml`; it builds the site and publishes the `dist` output after a push to `main`.

## Confirm before launch

- Registered business name: shown as `ASR Trading` until confirmed.
- Contact email: `hello@asrtrading.example` is a reserved placeholder and must be replaced.
- Confirm the active product list, destination coverage, and actual service scope.
- Review all commercial/legal wording with qualified advisers before using it for live offers.

No client logos, certifications, inventory, trade volumes, completed deals, or live vessel positions are represented. The route illustration is not suitable for navigation or logistics planning. The enquiry flow opens a local email draft; this site has no backend and stores no form submissions.
